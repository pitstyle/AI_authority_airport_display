# Realistic Split Flap Display

A Pen created on CodePen.

Original URL: [https://codepen.io/branlok/pen/qBQEGJy](https://codepen.io/branlok/pen/qBQEGJy).

Inspired by the people on youtube that gave tutorials on making a real mechanical split flaps. I thought it would be fun to create a digital version. I tried to mimic as close as possible to the nature of the machinery. For example, the asynchrony to arrive at destined letter is due to the variation in symbol placed on the rotary, a key characteristic of split-flap visual appeal. 

This is just a sample, would love to add more customization down the road.
